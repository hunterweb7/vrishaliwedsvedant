# vrishaliwedsvedant

Wedding invitation website for Vrishali & Vedant, in English (`/en/`) and Marathi (`/ma/`).

- Edit `src/template.html`, then run `node build.mjs` to regenerate `en/index.html`, `ma/index.html` and the root `index.html`.
- The site is static: host the repository root as-is (no build step needed on the host).
